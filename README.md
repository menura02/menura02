### 🔍 PySyntaxHighlight
A real-time syntax highlighter I built with Python and Tkinter as a learning project. I wanted to understand how tokenization and parsing actually work, so I implemented my own basic Lexer and Parser instead of reaching for existing tools. Learned a ton from it.

### ⏱️ Flexible Attendance Tracker
A web app for companies to track employee working hours. It parses uploaded Excel/CSV files and calculates flexible hours, lunch breaks, and overtime automatically. `Python · Flask · MS SQL · Waitress`

### 🏭 X Textile Management System (ERP)
A full-blown management system for a textile company. It tracks everything from yarn purchasing and weaving to dyeing, inventory, and sales. `PHP · MariaDB · Bootstrap`
